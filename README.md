About the Project
This project is a smart blind stick built to help visually impaired people move around safely and on their own. A normal white cane only helps with things the person can touch. Our stick uses sensors to detect obstacles ahead of time and warns the user before they reach them. The data is also sent to a frontend so the stick's status can be monitored.

What is in this Repository
The prototype.jpg file is a photo of our hardware prototype. Frontend.jpg, Frontend (1).jpg and Frontend (2).jpg are screenshots of the frontend interface. Smart blind stick .mp4 and Smart blind stick working.mp4 are videos that show the project and how it works in real time.

Applications
The stick can be used for everyday navigation by visually impaired people, in public places, and as a base for more advanced mobility aids.

Future Scope
We plan to add GPS tracking, an emergency alert to family members, voice guided navigation, and detection of water and pits on the path.
